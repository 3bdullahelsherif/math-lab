# blue calculator 💙

a cute little blue calculator — **plain HTML + CSS + JavaScript, no libraries.**

## Run

Open `index.html` in your browser, or visit the live version:

🔗 https://3bdullahelsherif.github.io/math-lab/

## Features

- 🧮 basics + √, x², 1/x, π, %, +/−
- ⌨️ full keyboard support
- 🎨 soft blue theme

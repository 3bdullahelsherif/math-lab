# مختبر الرياضيات 🧮

آلة حاسبة وحلّال معادلات (من الدرجة الأولى والثانية) مع خطوات الحل بالعربي.

**HTML + CSS + JavaScript خالص — بدون أي مكتبات.**

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو زر النسخة المنشورة:

🔗 https://3bdullahelsherif.github.io/math-lab/

## المميزات

- 🧮 آلة حاسبة كاملة (العمليات الأساسية + √ و x² و 1/x و π و % و ±) مع دعم لوحة المفاتيح
- 📐 حلّال معادلات من الدرجة الأولى `a·x + b = 0`
- 📈 حلّال معادلات من الدرجة الثانية `a·x² + b·x + c = 0` مع المميّز Δ وكل الحالات (حلّين، حل مكرر، حلول مركّبة)
- 📝 عرض خطوات الحل خطوة بخطوة بالعربي
- 🎨 تصميم RTL عربي بألوان Global Math
